# Allmaths standards

These documents are the **global rules** of the platform. Every person and every tool (Claude Code, another AI assistant, a new developer, a content author) follows them, for every course and every level, from secondary school to doctorate. When something here and a single lesson disagree, this folder wins and the lesson is corrected.

| Document | What it fixes |
|---|---|
| [vision-and-scope.md](vision-and-scope.md) | What the platform is, for whom, the levels it covers, the principles that are never traded away |
| [curriculum-structure.md](curriculum-structure.md) | The hierarchy (course, module, unit, lesson, section), ids, levels, **the one lesson template**, exercises, final answers, tests, the definition of done of a module |
| [notation-and-naming.md](notation-and-naming.md) | One notation for the whole platform (numbers, sets, functions, calculus, vectors, geometry, linear algebra, probability), exact values, units, spelling, titles and writing style |
| [public-site.md](public-site.md) | The public pages (what is inside, how it works, how progress is counted, the team), and the visual and accessibility rules |
| [solver.md](solver.md) | The target of the step-by-step solver: no AI, verified answers, coverage by level, how coverage is measured and grown |
| [grapher.md](grapher.md) | The target of the grapher: a GeoGebra-class 2D and 3D construction tool with exact values |
| [math-input.md](math-input.md) | One mathematical answer field for the whole platform: how learners type mathematics |

## Status words used in these documents

- **Rule**: decided; it applies now. Changing it needs the owner's agreement and an update here.
- **Proposed**: the recommended standard, written before the owner's meeting with the lecturer; it is confirmed or changed then. Until it is confirmed, existing content stays as it is and new work follows the proposal.
- **Target**: where a part of the platform must arrive; the current state is described next to it, so that nobody mistakes the target for what exists.
- **Decision needed**: two rules conflict, or the owner must choose; the options and a recommendation are written down.

## Order of authority

1. The owner's decisions (and the lecturer's requirements as the owner records them).
2. This folder.
3. `CLAUDE.md` (the short version for daily work) and `MATH_PLATFORM_BUILD_SPEC.md` (the original specification). Where the spec and this folder disagree, this folder is the newer decision.
4. Existing code and content.
